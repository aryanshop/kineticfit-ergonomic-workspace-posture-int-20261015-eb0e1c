# KineticFit: Ergonomic Workspace & Posture Interval Coach

KineticFit is a polished, highly useful front-end productivity and wellness web application designed to help desk-bound professionals and remote workers optimize their physical workspace ergonomics, prevent repetitive strain injuries (RSI), and incorporate mindful movement intervals into their daily workflow.

## Features

1. **Ergonomic Workstation Calculator**
   - Input your height, desk height, chair height, monitor distance, and monitor elevation.
   - Receive a real-time ergonomic health score out of 100 with dynamic diagnostic feedback and actionable advice.

2. **Posture & Focus Interval Coach**
   - Integrated Pomodoro-style focus timer with visual circular countdown animation.
   - Automatically triggers an "Active Break" mode offering randomized desk stretches and eye-rest exercises with built-in audio chimes.

3. **Desk Stretch & Posture Library**
   - Explore curated 1-minute stretches tailored specifically for remote desk workers (neck, shoulders, wrists, and spine mobility).
   - Interactive modal guides featuring step-by-step instructions and a built-in 30-second interval countdown timer.

## Local Run Instructions

1. Ensure all files (`index.html`, `style.css`, `script.js`, `README.md`) are saved in the same directory.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build step, package manager, or server setup required. All calculations and timers run entirely client-side using vanilla HTML, CSS, and JavaScript.

## Technical Stack

- **HTML5**: Semantic elements, accessible structure and modal dialogs.
- **CSS3**: Custom properties, responsive flexbox/grid layouts, smooth cubic-bezier transitions.
- **Vanilla JavaScript**: DOM manipulation, interactive interval state machines, and Web Audio API synthesis for gentle break chimes.

## Static Project Notice
This project is entirely static with no external trackers, network requests, or data storage.
